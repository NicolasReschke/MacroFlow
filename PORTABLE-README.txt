MacroFlow 0.2.0 - Windows x64
================================

1. Extraer todo el contenido del archivo ZIP.
2. Ejecutar MacroFlow.exe.
3. No es necesario instalar .NET.

Los perfiles se guardan en:
Documentos\MacroFlow\Macros

Controles predeterminados:
- F6: iniciar o detener la secuencia.
- F12: parada de emergencia.
- Q: pausa mientras se mantiene para parry.
- M: alternar pausa de morph.
- Ctrl + F8: iniciar o finalizar una grabación.

MacroFlow genera entradas de teclado y mouse mediante las funciones estándar de Windows.
El proyecto no inyecta código dentro del juego ni incluye telemetría.

Windows SmartScreen puede mostrar una advertencia porque esta compilación no está firmada
con un certificado comercial. El código fuente está disponible en:
https://github.com/NicolasReschke/MacroFlow
