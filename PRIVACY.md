# Privacidad

MacroFlow funciona localmente y no incluye telemetría, publicidad, cuentas de usuario ni conexiones de red.

- Los perfiles se guardan como JSON en la carpeta `profiles` junto al ejecutable.
- El hook global procesa únicamente eventos de teclas en memoria para reconocer los controles configurados.
- No se conserva un historial de teclas ni se transmiten datos.
- MacroFlow no lee memoria, archivos ni tráfico de otros procesos.

El código puede auditarse y compilarse desde este repositorio.
